# KiDDY SHOP — Premium Render Ready

## Render
Build Command: npm install
Start Command: npm start

Recommended environment variables:
- ADMIN_PASSWORD=your-private-password
- DATABASE_URL=your-Render-PostgreSQL-url

Admin: /admin.html

Features: user-supplied logo, premium kids storefront, categories, products, product details, cart, checkout, order tracking endpoint, auto-scrolling reviews, review submission, Bangla/English assistant, separate admin panel, order status and review management. PostgreSQL is supported for production; the app also boots with in-memory data for demo/testing.
